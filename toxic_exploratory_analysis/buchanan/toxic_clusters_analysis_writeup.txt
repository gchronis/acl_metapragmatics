SEMANTIC FEATURE ANALYSIS OF "TOXIC" USAGE CLUSTERS
====================================================

1. METHODS
----------

We analyzed semantic feature profiles of the word "toxic" across two corpora:
ACL Anthology papers (academic NLP literature) and COCA (Corpus of Contemporary
American English, representing general discourse). Contextualized embeddings were
extracted from RoBERTa (layer 7) for each token instance of "toxic" (N=5,170 tokens;
ACL=2,585, COCA=2,585). Joint k-means clustering across both corpora yielded 9
clusters capturing distinct usage patterns.

For each cluster, we conducted three analyses using Buchanan semantic feature norms:
(1) Feature activation profiles: Mean predicted values for 1,373 semantic features
(2) Cluster distinctiveness: Logistic regression predicting cluster membership vs.
    all other clusters from each feature (identifies features characterizing each usage)
(3) Source differences: Logistic regression predicting corpus source (ACL vs. COCA)
    within each cluster (identifies how academic vs. general usage differs)

Infrequent features (N=2,608 with <10 ratings) were excluded. Positive regression
coefficients indicate higher feature values predict cluster membership or COCA source;
negative coefficients indicate prediction of other clusters or ACL source.

3. SUMMARY
----------

The semantic feature analysis reveals distinct usage patterns for "toxic":

ACADEMIC (ACL) DOMINANT CLUSTERS:
- Cluster 1, 2, 4, 6, 7, 8: Technical NLP terminology for content moderation,
  detection systems, annotation, and classification methodology

GENERAL (COCA) DOMINANT CLUSTERS:
- Cluster 5: Literal chemical/biological toxicity (environmental, medical)
- Cluster 0, 3: Metaphorical social toxicity (relationships, leadership, environments)

Key findings:
1. Academic usage focuses on computational operationalization of toxicity
2. General usage maintains both literal (chemical) and figurative (social) meanings
3. Within shared clusters, academic usage emphasizes functional/abstract features
   while general usage emphasizes concrete/physical features
4. High separation in feature profiles enables accurate source prediction within
   most clusters (accuracy >90% in several cases)
